# Sounds

Die Kampf-Sounds sind echte Aufnahmen. Leg die Dateien einfach in diesen Ordner, der Name bestimmt, wofür sie gebraucht werden. Vite findet sie beim nächsten Neuladen automatisch, Code muss man dafür nicht ändern.

- Formate: `.ogg` (empfohlen, klein), `.mp3`, `.wav` oder `.m4a`
- Varianten: `hit-light.ogg`, `hit-light-2.ogg`, `hit-light-3.ogg` … Beim Abspielen wird zufällig eine gewählt und leicht in der Tonhöhe variiert. Bei Treffern lohnen sich 3–5 Varianten.
- Fehlt eine Datei, spielt das Spiel einen dezenten Ersatz aus gefiltertem Rauschen.

| Name | Wann | Was passt gut |
| --- | --- | --- |
| `hit-light` | leichter Treffer | kurzer Metall-Klirr, Klingen-Clash |
| `hit-heavy` | harter Treffer | schwerer Metall-Einschlag mit Druck |
| `deflect` | Angriff prallt ab | heller Metall-Ping, Schwert-Parade |
| `smash-hit` | Treffer des Vernichtungsschlags | riesige Explosion oder Einschlag, gern mit Nachhall |
| `ult-cutin` | Ult-Einblendung (jede Ult) | Anime-Whoosh mit Impact, „Power-up“-Hit |
| `ult-ready` | eigene Ult ist bereit | kurzer, heller Energie-Ton |
| `ult-smash` | Vernichtungsschlag | Feuer-Fauchen, Flammenstoß, Brüllen |
| `ult-shield` | Schildwall | Energie-Schild, Kraftfeld fährt hoch |
| `ult-rush` | Ansturm | elektrisches Knistern, Blitzeinschlag |
| `ult-surge` | Zweiter Wind | Windstoß, Wirbelsturm |
| `burst` | Burst-Finish | Explosion mit klirrenden Teilen |
| `ring-out` | Ring-Out-Finish | Whoosh plus dumpfer Aufprall |
| `spin-out` | Kreisel dreht aus | auslaufendes Surren, klapperndes Metall |
| `launch` | Start, Kreisel fliegen ins Stadion | Reißleine, schneller Whoosh |
| `countdown` | 3, 2, 1 | kurzer, tiefer Schlag |
| `countdown-go` | „Spin!“ und Zeitende | großer Schlag, Gong |
| `spin-loop` | durchgehendes Surren (Schleife) | Kreisel- oder Turbinen-Surren, nahtlos loopbar, 1–3 s |

## Freie Quellen

Nur Sounds nehmen, deren Lizenz die Nutzung im Projekt erlaubt. Am einfachsten ist CC0, dann muss niemand genannt werden.

- **Kenney** (kenney.nl, CC0): „Impact Sounds“ (Metall-Treffer) und „Sci-Fi Sounds“ (Energie, Schild)
- **Pixabay Sound Effects** (pixabay.com/sound-effects): frei nutzbar, gut für Feuer, Blitz, Explosion und Whoosh
- **Sonniss GDC Game Audio Bundle** (sonniss.com/gameaudiogdc): riesige, lizenzfreie Profi-Sammlung
- **Freesound** (freesound.org): beim Download auf die Lizenz achten (CC0 oder CC-BY mit Namensnennung)

Bei Sounds, die eine Namensnennung verlangen, gehören Titel, Autor und Lizenz in `CREDITS.md` in diesem Ordner.
